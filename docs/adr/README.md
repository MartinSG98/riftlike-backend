# Architecture decision records

One file per decision, numbered in the order the decisions were made. A record is never edited into something else after the fact. If a decision changes, a new record supersedes the old one and the old one's status is updated to point at it.

Each record answers three questions. What was the situation, what did we decide, and what follows from that.
